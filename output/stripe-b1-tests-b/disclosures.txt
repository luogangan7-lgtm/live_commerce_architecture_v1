   compile in Go (RE2 repeat limit 1000). Tests check the class/host by regexp and the 1..4000 bound by length.
2. SP13 "account_unregistered" cannot occur over HTTP any more (account derives from the immutable endpoint row).
3. Foreign buyer's handoff: contract says 404; the frozen provider probe returns NULL for a foreign order so
   the PAYUNi path (409 conflict) answers. Test accepts 404 or 409 and only forbids a disclosed URL.
4. Handoff after the cutoff is UNAVAILABLE in SQL (contract text lists "CLOSED/cutoff/UNAVAILABLE"); CLOSED needs
   a CAPTURED/CLOSED_UNPAID fact. Tests assert exactly that.

   the Go layer responsible. The PAYUNi goldens go red if it is not masked (red-SP14.log).
6. SP09 400-after-uncertain-send is guarded twice (worker mark==SEND and record_stripe_observation
   create_send_count<>1). The red proof needs both layers mutated; a single-layer mutation stays green.
7. cmd/stripe-admin: exact flag names of `method` and whether CLI `qualify` accepts PROVIDER_MOCK are not frozen;
   the env-read test asserts only subset-of-allowed and no leakage.
8. operations.provider_reference is '' (not NULL) after start.
9. SP11 is "over HTTP" in the brief; throttle/cap/set-once are asserted over HTTP in SP14 and once over HTTP with
